SAME TREE
All five levels survive. L1 is the bottom bar, L2 a drill screen, L3 a titled band, L4 a sheet, L5 a full screen.
ONE OPEN

MAP VISIBLE
Sheets cap at 60% height. Anything that changes pixels is read while its result is on screen.
TARGETS
52 dp list rows, 48 dp buttons, 44 dp icon buttons, 22 dp slider thumbs, 14 dp gradient stops with a 44 dp touch pad.
HEAVY PASSES
Erode, weather, bake and simulate confirm inline with a device time estimate before they run.
BACK
System back leaves a sheet, then the L2 screen, then the viewport — never the app.
